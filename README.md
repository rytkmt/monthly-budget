# monthly-budget

月ごとの外食予算に対する残金を、ひと目で確認できる iPhone 向けの家計アプリ（PWA）です。外食のたびに「いつ・何円・なにに」を記録し、予算 − 使用額 = 残金を大きく表示します。

- 公開 URL: https://rytkmt.github.io/monthly-budget/
- データは端末の IndexedDB だけに保存します。サーバーには送りません。

## 使い方

### インストール（iPhone）

1. Safari で公開 URL を開きます。
2. 共有ボタン →「ホーム画面に追加」を選びます。
3. 以後は、ホーム画面のアイコンから起動します。オフラインでも使えます。

Safari のタブのまま使うと、7 日間開かないとデータが消えることがあります。必ずホーム画面に追加して使ってください。

### 基本の操作

- **予算を決める**: 残金の表示をタップするか、右上の ☰ を開いて、その月の予算を入力します。
- **支出を記録する**: カレンダーで日を選び、金額と内容（20 字まで）を入れて「追加」を押します。同じ日に何件でも登録できます。
- **確認・修正する**: 日付セルに日別の合計額が出て、金額が大きいほど色が濃くなります。日を選ぶと明細が出て、編集・削除ができます。
- **月を移る**: 上部の ‹ › で前後の月へ移れます。過去の月も編集できます。
- **残金の色**: 予算の残りが 50% 以下で黄、20% 以下で赤、超過するとマイナス表示の赤になります。

### 予算の引き継ぎ

月の予算は、月ごとに保存されます。予算を設定していない月は、直近の過去月の金額を引き継いで表示します。その月に最初の支出を追加した時点で、引き継いだ金額が保存されます。引き継ぎ元がない月では、先に予算を設定します。

### バックアップと削除（☰ メニュー）

- **書き出す**: 共有メニューが開くので「ファイルに保存」を選びます。機種変更やデータ消失に備えて、定期的に書き出してください。
- **読み込む**: 書き出した JSON ファイルを選びます。現在のデータは、すべて置き換わります。
- **過去データの削除**: 指定した月以前の支出と予算を削除します。予算は、直近の 1 件を残します。元に戻せないので、先にバックアップを書き出してください。

## 開発

ビルドは不要です。素の HTML・CSS・JS（ES modules）で、外部ライブラリは使っていません。

```sh
python3 -m http.server 8080   # http://localhost:8080/ で開く
node --test                   # ユニットテスト（src/domain/ の純粋関数）
```

- IndexedDB 層の確認: 配信中に `/dev/db-check.html` を開くと、PASS / FAIL が表示されます。
- 仕様、設計、判断の経緯: [SPEC.md](SPEC.md)
- 機能の変更は、先に SPEC.md を更新してから実装します（手順は SPEC.md 末尾）。

### 公開

`main` ブランチを push すると、GitHub Pages が自動で再公開します（反映まで約 1 分）。ファイルを追加したときは、`sw.js` の `PRECACHE` 一覧に追記し、`CACHE_VERSION` を上げます。
